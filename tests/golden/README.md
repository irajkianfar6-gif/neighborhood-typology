# آزمون‌های طلایی (Golden)

برای هر محلهٔ مرجع (مثلاً `tehran:m605`) یک کارت تأییدشده توسط کمیتهٔ روش‌شناسی به شکل
`<neighborhoodId>.expected.json` نگه داشته می‌شود: سطح انتشار، کدهای امتیازدار، بازهٔ مجاز هر امتیاز (±tolerance)،
تیپ تشخیصی و گلوگاه. اجرای دوباره با همان `reproducibilityKey` باید در این بازه‌ها بماند؛ هر انحراف بیرون از بازه
یعنی تغییر روش یا داده که باید نسخه‌گذاری و دوباره تأیید شود.

تا وقتی دادهٔ قراردادی واقعی و پیمایش تأییدشده وجود ندارد، فایل طلایی ساخته نمی‌شود (ساختن آن از دادهٔ مصنوعی خلاف اصل عدم ساخت عدد است).
